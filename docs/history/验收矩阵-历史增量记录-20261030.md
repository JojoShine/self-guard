## 可复现验证命令与证据边界

以下命令在仓库根目录执行。必须以实际输出为准；依赖已有开发容器和本地测试凭据。禁止把生产目标作为权限修复测试文件。

```sh
docker exec selfguard-dev-api-1 npm run build
docker exec selfguard-dev-api-1 npm test
# 集成测试必须设置 TEST_API_URL、ADMIN_PASSWORD、ENROLLMENT_TOKEN 等测试配置；
# 未设置 TEST_API_URL 时 integration.test.ts 会跳过，不算集成通过。

docker run --rm -v "$PWD/services/waf:/src" -w /src golang:1.27.3-alpine go test ./...
docker run --rm -v "$PWD/services/agent:/src" -w /src golang:1.27.3-alpine go test ./...
# 有完整Go与C编译器的环境另行执行：go test -race ./...
```
