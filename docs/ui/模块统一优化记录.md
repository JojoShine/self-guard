# 模块页面统一优化

2026-10-31。沿用《设计系统V1》，根据用户后续反馈调整页面宽度与留白，并将规范应用到其他现有模块。没有更换前端技术栈或增加业务能力。

## 最新间距规则

- 页面铺满可用工作区，取消1680px最大宽度和居中外边距，宽屏不再额外增加左右空白。
- 常规页面与顶栏基础边距32px；800px以下水平16px，600px以下12px。
- 表格内部左右20px，800px以下16px；表头与首尾列统一设置，标准、紧凑、宽松密度均保留内边距。
- 侧栏保持232px展开、72px折叠。表格自身滚动，不以加大整个页面宽度容纳宽表。

## 已统一的页面

| 范围 | 更新 |
|---|---|
| 全部通用列表 | 页面留白、表头/首尾列内边距、结构化内容折叠、日期格式与宽表滚动 |
| 业务、趋势、导出、凭据与平台运维 | 统一内容区块，保留真实刷新、空态及危险操作确认 |
| 规则范围与样本 | 规则选择、适用范围、豁免、只读测试和结果分区；重复字段使用弹性网格 |
| 关联检测、遥测、WAF策略测试 | 中文状态、响应式查询/条件表单、权限禁用说明；证据按需展开，保留脱敏结果 |
| 漏洞数据源、站点证书 | 说明折叠、统一操作区与列表；来源/证书弹窗使用响应式字段，加载失败时禁用不可执行操作 |
| 修复模板、修复批次 | 说明、目录与批次列表分区；模板步骤完整保留；候选任务状态中文化 |
| 安全报告 | 筛选、已应用范围、导出、统计、业务与趋势分区；下载与打印继续使用已生成报告 |
| 审批策略、数据保留、存储设置 | 配置字段网格化、状态反馈及明确提交区；数据使用情况与清理配置分区 |
| 导入、通知、外部投递 | 导入/通知列表及空态、错误、加载反馈；投递状态中文化、日期统一 |
| 灰度升级、备份、外部通知配置 | 中文配置概要，原始字段折叠保留；提交忙碌状态、弹窗内部滚动 |
| 详情子模块 | 资产历史切换时隐藏旧对象记录并重置页码；处置工具与弹窗统一间距及提交状态 |

共享组件位于 `apps/web/src/ModuleSection.tsx`，共享布局位于 `apps/web/src/module.css`，基础令牌仍位于 `apps/web/src/theme.ts`。页面不再在统一区块外重复套内容卡片；定制模块保留自己的有效刷新和主操作，移除页头重复或无效操作。

## 验证口径

本轮按用户要求，以代码审查、类型检查、生产构建和前端测试为主，未持续进行逐页计算机操作。响应式规则覆盖常规窗口、1024、800/768及600以下布局，包含页面、表格、表单和弹窗内部；不将源代码检查宣称为每个页面都完成了视觉截图验收。

前端25项测试通过，包含新增共享状态的业务含义、未知状态与异常日期处理。类型检查与生产构建通过。日志见 `.artifacts/results/ui-modules-tests.log` 和 `.artifacts/results/ui-modules-build.log`。报告原CSV/HTML转义、真实API及审批/回滚/证据权限限制保持原逻辑；未通过测试实际执行清理、凭据变更、升级或通知投递。
