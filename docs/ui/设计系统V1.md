# Self Guard 设计系统 V1

日期：2026-10-31。适用范围：登录、导航、工作台、卡片、列表、筛选、详情、表单、反馈。前端继续使用 React/Vite/Ant Design；工作区默认浅色。本规范细化根目录《产品设计规范》，用户最新反馈优先执行。

## 1. 品牌与视觉方向

专业、清晰、克制的安全运营控制台。深蓝灰导航作为稳定的产品边界，浅灰页面和白色内容承载数据，蓝色表示主要操作，风险和流程状态使用各自语义色。使用系统中文字体，避免额外字体网络加载。

Logo 使用 SG 双层边界标记，蓝色主体与少量浅青辅助面表达发现、控制、恢复的闭环。单独标记与 Self Guard 文字组合分别用于标签页、折叠导航、完整导航和登录。最小标记显示24px，常用36/40px；四周至少留标记宽度的1/4，不压缩变形，不用Emoji或通用盾牌替代。

实际资源：`apps/web/public/brand/selfguard-mark.png`。初版为透明PNG，通过内置图像工具生成；完整提示词见同目录品牌资源说明。不将位图宣称为矢量源文件。

## 2. 设计令牌

唯一代码基线为 `apps/web/src/theme.ts`：同时提供 Ant Design ThemeConfig 与全局CSS变量。页面引用变量，不再自由定义一套相近色和间距。

| 轻强调 | #EDF3FF | 当前筛选、轻量提示 |

| 内容 / 次级面 | #FFFFFF / #F8FAFC | 卡片、筛选辅助区 |
| 主 / 次 / 辅助文字 | #202B40 / #657187 / #6B778B | 标题正文 / 说明 / 非关键辅助 |
| 边界 / 控件边界 | #E4E9F2 / #D5DDEB | 内容分隔 / 输入框 |
| 导航 / 悬停 / 选中 | #142037 / #1B2C48 / #244477 | 统一深蓝灰导航 |

成功与待核对背景必须显式绑定到Ant Design语义令牌 `colorSuccessBg` / `colorWarningBg`，不能依赖深色前景自动生成背景色。绿色/橙色预设标签、详情状态与工作台状态共用以上浅色背景。

图表使用独立的鲜亮色板：蓝`#3478F6`、绿`#22C55E`、橙`#FA8C16`、红`#FF4D4F`、青`#13C2C2`、紫`#9254DE`，轨道底色`#EEF4FF`。资产在线/心跳超时/从未上报/已归档分别使用绿/橙/青/紫；业务资产和风险使用蓝/橙。折线、柱形与图例共用图表令牌，状态标签继续使用既有语义配色。

安全运营趋势不设置内部纵向滚动区。卡片随图例、提示和展开的每日数据自然增高，交由页面滚动；不得通过隐藏溢出来裁切内容。每日数据表不限制纵向高度，窄窗口保留表格必要的横向滚动。相邻Web防护卡片保持紧凑，不随展开的每日数据拉长。

字号：页面26/600，区块16/600，正文14/400或500，辅助12/400，核心指标28–32/600。数字使用等宽数字排布；表格不因窄屏缩小正文。普通按钮、表格行内按钮及“更多”下拉菜单统一14px/400；按钮是否带图标、位于列表或浮层不改变文字字号与字重。只有记录标题等明确的文字链接沿用蓝色/600。

间距采用4px基准：4/8/12/16/20/24/32。桌面内容边距32，窄窗口16；区块间20或24；卡片内20；控件间8或12。表单网格的纵向间隔统一20px，由网格row-gap管理；直接字段项与提示框不再叠加下边距。提示框、操作组与后续字段同样保留20px，窄屏单列也不取消纵向间隔。控件圆角6，内容卡片10。阴影仅用于浮层或必要的悬浮反馈，内容卡片主要用边界表达。

## 3. 布局与导航

- 展开导航232px，折叠72px；主区域可收缩，页面铺满可用工作区，不设置固定最大外宽或居中外边距；常规两侧32px、800px以下16px、600px以下12px。大屏不能额外产生随窗口增长的两侧留白；表格仅在面板内部滚动。
- 侧栏菜单隐藏可见滚动条，保留鼠标滚轮、触控板、触屏和键盘滚动能力；菜单超出视口时仍可访问末尾条目。
- 流量捕获的模式切换采用内容宽度的 Ant Design 下划线页签，14px 字号、24px 页签间隔，选中显示主蓝文字和下划线，未选中保持辅助色；不拉伸为整行灰底。流量捕获表单的字段提示与底部操作组保持20px，窄屏同样保留。
- 菜单图标统一采用 Ant Design outlined 图标，18px；折叠保留图标、完整可访问名称和提示。
- **多个菜单分组可以同时展开**。切页仅确保当前分组展开，不能关闭其他已展开分组；用户主动收起独立生效。
- 顶栏高度64，面包屑与账户信息分离；页面标题区包含具体说明及一个主要操作，其余为次级操作。
- 右上角固定提供带文字的“操作指南”入口，窄窗口仍可识别和点击。指南使用独立Markdown阅读页，不显示系统侧栏和卡片。桌面左侧为文档目录，右侧为Markdown正文；目录根据正文标题生成并定位章节，不改变应用路由，窄屏目录移到正文上方。正文连续展示所有模块，阅读容器最大1120px并水平居中，容器内保留32/16/12px响应式边距，顶栏内容与正文对齐；顶栏提供返回系统，文档链接使用主蓝/600并跳转到正确菜单。
- 页面级刷新不改变筛选、分页及展开状态。切换资源时清除上一类记录，避免新页面短暂展示旧数据。

- 操作指南按功能解释与业务操作路径编写，避免逐菜单重复操作口号。说明应覆盖功能作用、输入参数、数据或状态变化、具体示例、结果判断和异常处理。文档目录分章节独立展开并跟随阅读位置高亮；目录导航使用中性色和400字重，仅当前小节使用主蓝/600及浅蓝选中背景，左侧展开符号使用小号辅助色；章节上下内距12px、子目录10px、章节组间12px，目录保留透明底色且不设外框；正文业务链接仍为主蓝/600；字段与状态用表格比较，关键结论用提示块，步骤与代码示例使用统一排版，静态Markdown正文不得因目录状态更新而重新挂载。目录点击产生的选中项优先保持，直至用户恢复正文滚动；底部章节不得被顶部位置监听反向覆盖，目录滚动不得传递到正文。正文与提示内容14px、辅助说明12px；段落间16px，表格/提示/代码块外距24px；表格正文14px、表头12px，单元格上下12px、左右首尾20px（窄屏16px），横向溢出限制在各自容器并支持键盘滚动。

## 4. 登录页

桌面分为品牌区和登录区。品牌区采用同导航的深蓝灰背景、Logo、产品名称和简洁价值说明；登录区为清爽白色表单，宽度约380px，周围留充足空间。品牌强调通过真实Logo及排版实现，不用伪造安全分数、动效地图或黑客终端。

表单输入高44，标签14，字段间20，主按钮高44并占满表单宽。邮箱和密码带明确标签、焦点和错误；支持Enter提交、密码查看和加载反馈。账户提示使用真实能力，不提供无功能的注册、忘记密码或保持登录开关。窄窗口缩短品牌区，表单保持可读。

## 5. 卡片与待办列表（对应用户引用图）

- 同级卡片统一标题区54、内容内边距20、边界与圆角；标题16/600，数量放在标题旁或明确指标位。
- 待办行常用64–72px，左右16；可点击标题14/600，默认主蓝、悬停加深；不可点击名称14/400、正常正文色。仅对真实交互入口使用链接样式，停用入口不保留蓝色和半粗字。
- 一行结构为“标题/必要补充信息在左，状态/动作在右”；长标题单行省略并能查看完整内容。状态不再紧贴标题下方制造参差。
- 分隔线使用淡色边界，首尾行不增加重复边线。卡片底部48px，左侧显示范围，右侧明确“查看全部”。
- “结果未知”使用琥珀色+明确文字，“待审批”使用有区分的轻量流程标识；风险严重程度另列，不能混同。
- 工作台八个概览指标全部使用同级指标卡，桌面四列两行，窄窗口两列。安全运营趋势以真实最近30天数据绘制折线；WAF累计计数与趋势分开说明口径。我的工作、资产状态、业务风险分布、修复结果在桌面采用等宽2×2网格，各卡456px等高；1100px以下改为单列，内部列表或图表滚动。资产状态、业务风险、修复结果使用数量柱形，保留业务分页。首页指标、图表、待办及最近记录点击后直接进入对应菜单模块，菜单同步选中，不打开统计弹窗或记录抽屉。WAF攻击记录进入Web防护下的攻击记录列表。空态不伪造记录，零值不绘制正长度柱形。

## 6. 数据表格与筛选

标题与操作 → 常用筛选 → 已生效条件/结果数与工具 → 表格 → 分页。常用搜索、严重程度、中文状态一行，日期/业务/负责人/资产/排序进入高级筛选。保存视图、列设置、密度属于表格工具，不抢占主搜索位置。

表格内部左右保留20px内边距，800px以下16px；首尾单元格和表头保持一致，不得贴住卡片边框。表头约42–44px，标准行约52–56px；正文14，日期/来源说明12，数字对齐。仅标题/必要入口可点击，避免整行高亮蓝色。状态使用文字、图标/圆点与背景，不能只用颜色。保留宽表横向滚动、分页、精确筛选、导出和返回上下文。

正式列表默认每页15条，提供15/30/50/100条切换并显示总数。服务端分页切换数量时返回第一页，请求pageSize与显示数量保持一致；主列表的分享链接和保存视图同时保留分页数量，旧链接和旧视图默认15条。前端分页、资产历史、附件、版本、关联列表与每日数据表共用分页配置；首页最近记录摘要及业务图表分组数量沿用概览布局，不作为完整列表分页。

数量选择器在375px等窄窗口也必须可操作，不采用组件默认的隐藏策略，空间不足时换行。服务端结果总数减少后自动重新请求有效页，不能让分页显示与行数据脱节。未提交的表单筛选不影响切页；已提交条件随切页、数量切换保留。失败请求保留上次成功的数据与分页状态；新模块隔离旧模块状态和迟到响应。报表重新筛选回到第一页并保留所选数量；切换详情记录时附件、版本和关联列表重新从第一页展示。

节点与访问日志必须提供items和total，按page/pageSize查询并采用唯一标识补充排序以稳定翻页。节点时间条件和默认排序对应最近心跳，访问日志对应访问时间，筛选标签不得标成不存在的创建时间。

## 7. 按钮与交互

主要按钮36高、登录/关键提交44高；普通按钮36，表格行内动作28高。主按钮每个操作区域原则上一个；普通编辑用次级按钮，低优先动作使用文字按钮，危险操作红色并保持现有审批/确认。

状态标签统一24px高、12px字号、20px行高，左右8px内边距、4px圆角；列表、详情、工作台和组件预览共用同一套组件。待审批/处理中使用蓝色，待确认/结果未知使用琥珀色，验证通过使用绿色，失败/阻断使用红色；停用、取消等中性状态使用灰色。风险严重程度独立使用等级标签：严重/高为红、中为琥珀、低为蓝、信息为中性，不能把等级当作流程状态。未知或未完整判定的检测结果不得显示绿色“未命中”。

按钮文本使用动词和对象，例如“创建任务”“导入发现”。图标按钮需名称和提示；悬停/聚焦/禁用/加载有一致反馈。焦点环清晰，不用取消outline隐藏焦点。动效120–180ms，仅用于状态反馈，遵循减少动态效果偏好。

全局关闭 Ant Design 按钮的双汉字自动插空格（`ConfigProvider.button.autoInsertSpace=false`），按钮文字按原文展示；不能用文字空格模拟左右内边距。按钮内边距和按钮之间的间距分别由组件及操作组控制。

需要核对影响的操作优先在当前页面展开确认区，展示明确记录、版本或目标范围；返回不写入，失败保留原因与重试入口。安装授权撤销、发行发布/撤回、SSH批次开始/取消均采用页内确认。切换标签、筛选或分页时清理原确认区；在途操作完成后刷新当前列表条件，不能把旧页结果写入新页。

Web 防护按独立交互规范执行：事件、访问日志、规则报告、导入、样本回放、观察发布、阻断切换、回退和策略测试结果使用右侧抽屉；站点编辑与历史恢复使用居中弹窗。业务表单及详情不得派生到主页面下方。说明提示与搜索、操作区域至少间隔16px。列表标题使用实际规则说明或请求方法与响应状态，不以不可读标识代替业务名称；原始标识仅在详情中作为辅助定位信息保留。访问日志使用当前已授权加载的真实记录查看，不调用不存在的详情入口。

同一操作组按钮横向及换行间距8–12px，不同操作组之间16px；工具栏与说明文字、上传操作区与附件表格之间至少16px。使用Ant Design Upload提供附件选择及上传反馈，日期使用DatePicker，带时间的字段启用时间选择；不得用原生文件、日期输入框代替。UTC日期筛选保留日期本身，执行窗口等本地日期时间在提交时转换为接口ISO时间。

详情主操作栏使用直接的弹性布局，统一横向与换行间距8px。条件分支和片段不得额外生成占位项；避免在Space子项中插入显式空白文本导致多算间距。验收应测量相邻可见按钮的实际边缘距离，不能仅检查父容器的gap值。

动态规则、豁免和样本条目按独立分组排布，分组之间16px，末尾添加动作与后续字段之间20px；新增与删除按钮在窄窗口换行后也必须保留间距。查询提交使用表单项与同一行输入控件对齐。配置描述与展开详情之间16px。业务按钮、输入、选择与页面表格复用Ant Design组件；图表的点击入口也沿用按钮的焦点、禁用和交互状态。

文字入口统一覆盖列表名称、页脚快捷入口、链接式按钮、外部文字链接和折叠说明入口：可用时主蓝/600，悬停加深。禁用按钮、禁用跳转链接和禁用文字链接均为次级文字色/400，不得触发跳转；同时识别原生disabled、组件禁用类和aria-disabled。普通列表名称、备注和时间线作者使用正常正文样式。菜单跳转后叶子项应准确选中；导航收起时对应菜单组保留选中反馈。站内严重问题通知进入“全部发现”，覆盖风险和告警，不固定跳入风险列表。

## 8. 详情与证据

先显示对象名称、严重程度、状态、负责人/业务及关键时间，再显示处置动作、证据、关联与历史。ID放次级可复制区域；JSON证据解析为字段、窗口、条件或列表，已留存原始字段默认使用分页表格展示，包括未知字段、嵌套对象和数组，并保留原字段名与复制JSON入口；不通过折叠隐藏原始字段。绝不通过显示层恢复已隐藏证据，不使用innerHTML执行日志内容。

## 9. 验收

真实登录页、工作台、全部发现、风险/任务详情、卡片/列表和按钮在1920/1440/1280/1024/768宽度检查；窄屏导航仍可识别，允许多个菜单分组同时展开。所有数量、状态和数据来自原接口；检查加载、空态、无权限和错误。以真实浏览器改前/改后截图和核心流程回归验收，不能以主题代码存在替代视觉验证。

策略中心创建、编辑、范围/身份调整及详情统一使用右侧抽屉或居中弹窗，不在主页面向下派生操作区。父子详情在同一层级切换并提供返回，错误保留在当前弹层。来源、配置目标、实际连接与处置结果分别说明，不能把配置上游绘为已回源，不能把单次阻断表述为持续封禁。

菜单命名区分结果与配置：安全中心使用“事件调查”组织跨来源研判；Web防护使用“攻击记录”查看请求命中。“检测规则”管理已创建的检查条件，“数据安全规则”从基础模板创建规则，“规则适用范围”维护资产、业务、标签和基线豁免，“规则样本验证”仅核对离线样本。范围与验证页面不得混入另一套编辑或测试表单。WAF规则与主动扫描模板继续在各自入口维护，页面说明、看板、面包屑和返回文案保持一致。


## 列表操作与单层面板

常用功能优先放在列表操作列，次要功能收进“更多”。标题用于查看记录及证据，不能成为所有操作的必经入口。查看、编辑和专用操作共用单层展示原则：从列表直接打开独立右侧抽屉或居中表单，不在详情抽屉之上再压一层抽屉/弹窗；从详情切换编辑时先替换详情展示。取消或完成列表操作返回原列表，保留筛选与分页。按钮显示、禁用原因与服务端权限一致，保存失败保留输入及错误信息。
