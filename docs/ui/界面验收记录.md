## 本轮验证

在实际运行的本地界面完成浏览器检查，未用静态稿替代实际页面：

- 1920、1440、1280、1024、768宽度检查；工作台、列表主页面未出现页面级横向溢出。宽表仅在面板内横向滚动。
- 768宽度：导航72px，核心指标两列，待办/资产状态纵向重排；列表内容窗口647px、表格内容900px，滚动局限于表格。
- 768宽度：详情抽屉744px，内部可用宽度729px，内部滚动宽度729px；完整标识与证据没有横向溢出。
- 768宽度下检查模板、规则范围、报告、数据保留、设计规范与登录；表单按空间换行，正文保持可读。
- 实际验证登录必填提示、密码回车提交、登出；桌面和窄窗口均显示真实Logo。
- 展开安全中心及修复中心后切到任务页，两组均保持展开；折叠菜单仍可打开并选择全部发现，选择后浮层关闭；重新展开恢复两组。
- 业务精确筛选及中文“待验证”状态筛选保留到地址参数，清空条件可恢复列表；高级筛选、显示设置可打开。
- 独立审查发现“最近发现 → 查看全部”的页面键不匹配，已改为导航使用的`findings`并补充回归断言。
- 前端22项单元/组件测试通过，包含证据双层JSON解析、隐藏内容、HTML纯文本、异常字段、指标绑定与列表入口；类型检查和生产构建通过。
