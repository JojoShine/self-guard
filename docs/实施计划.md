# Self Guard 初版实施计划

依据：根目录三份已确认文档。用户授权自主决策、连续实现与测试，不再设置人工确认门槛。

## 技术决策
- NestJS 模块化单体 + Prisma/PostgreSQL；React/Vite/Ant Design/Zustand。
- 独立 Go Agent 与 Go HTTP 反向代理 WAF；任务先使用 PostgreSQL 持久化，不引入消息队列。
- 本地部署绑定 127.0.0.1；管理会话和组件令牌分离；审批及修复状态由服务端约束。
- 原始事件初版有界保存到 PostgreSQL；容量和生产 HA 不作未验证承诺。
- 当前目录无 git 仓库，直接在用户指定目录建设，不复制到工作树。

## 阶段与验证
1. 基础：工作区、数据库、登录/角色/审计。验证未登录拒绝、只读不可写、登录限速。
2. 资产与检测：注册、心跳、清单、规则、发现去重、导入。验证重放不重复、组件只能上报自己的数据。
3. 安全与修复：全部发现、风险/告警/事件状态及关联、审批、任务领取与结果、独立复测。验证非法状态与重复执行拒绝。
4. Go Agent：有界采集、持久身份、离线队列、文件权限检查及修复。测试临时目录和 HTTP 测试服务器，不修改宿主机配置。
5. Go WAF：独立代理、规则/例外/限速、观察与阻断、日志。使用测试上游验证合法流量、攻击、更新与异常。
6. 前端：八个导航分区，真实 API、表格筛选、详情、创建/处理/审批、明确空态和错误。
7. 全链路：Docker PostgreSQL + API + Web；Go 单测、构建、API 集成测试与浏览器检查。记录已完成与未完成项，不将骨架算完整交付。

## API 合约
统一前缀 /api。JSON，错误 {message}。管理请求 Authorization: Bearer <session token>。
POST /auth/login {email,password} -> {token,user:{id,email,name,role}}; GET /auth/me。
GET /overview -> {assets,risks,alerts,incidents,pendingTasks,criticalRisks,recent:[]}。
资源 GET /assets|findings|incidents|rules|tasks|sites|audit|users -> {items,total}，支持 q,status,severity,kind,page,pageSize。
GET /:resource/:id -> 单对象。POST /:resource 创建，PATCH /:resource/:id 更新（仅支持字段与合法状态）。
Finding: {id,title,kind:RISK|ALERT,severity:CRITICAL|HIGH|MEDIUM|LOW|INFO,status,assetId?,source,evidence,createdAt,updatedAt}。
Asset: {id,hostname,os,ip?,business?,owner?,tags:[],lastSeen,inventory:{},createdAt}。
Incident: {id,title,severity,status,description,findingIds:[],createdAt,updatedAt}。
Rule: {id,name,kind:BASELINE|LOG|FIM|VULNERABILITY,enabled,severity,config:{},version}。
Task: {id,title,assetId,findingId?,template:FILE_PERMISSION,parameters:{path,mode},status,reason?,result?,createdAt}。
POST /tasks/:id/approve {}, /tasks/:id/reject {reason}, /tasks/:id/verify {resolved:boolean,evidence:string}。
POST /findings/import {items:[{title,kind,severity,source,externalId,assetId?,evidence}]}。
Site: {id,name,hostname,upstream,mode:OBSERVE|BLOCK,enabled,config:{},version}。

## Agent 协议
POST /agent/enroll，Authorization Bearer ENROLLMENT_TOKEN，body {hostname,os,ip?,agentVersion,identity} -> {assetId,token}。
POST /agent/heartbeat，Authorization Bearer 组件 token，body {inventory:{},findings:[{externalId,title,kind,severity,source,evidence}]} -> {ok:true}。
GET /agent/tasks -> {items:[{id,template,parameters,expiresAt}]}；领取后原子转为 RUNNING，不再次投递。
POST /agent/tasks/:id/result {success:boolean,evidence:string,details?:object} -> {ok:true}，成功仅进入 VERIFYING；失败 FAILED。
不允许 Agent 自动关闭风险。服务端独立验证结果由授权管理用户提交。

## WAF 协议
Go WAF 可独立加载 JSON 配置和热更新；管理平台 GET /waf/config，Bearer WAF_TOKEN -> {sites:[Site]}；POST /waf/events，Bearer WAF_TOKEN，{events:[{id,siteId,ruleId,path,method,action,remoteIp,timestamp}]}。仅有界脱敏字段，不存请求体。
