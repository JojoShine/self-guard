## 环境与运行边界

- 真实运行验证为本机 Docker Linux arm64、PostgreSQL17、Node22 和 Go 工具链。软件清单以实际工具与权限为准；Debian/Ubuntu 版本比较有正反测试，其他公告生态明确返回覆盖不足。没有宣称已逐一认证所有发行版或生产 systemd 主机。
- 配置修复限定一个 64 KiB 内、唯一字面 KEY=VALUE 的普通文件；服务操作限本地白名单。中断遗留恢复标记时先核对备份/系统状态，禁止直接重执行。自动读回通过只证明批准的变更；配置秘密无法从原始证据绑定时保留风险待安全复测。
- 日志/队列/中心行数均有上限；不承诺无损无限离线缓存。CPU/内存硬限制由 systemd/容器提供，Go 软预算和负载字节限速不是总磁盘或协议字节硬配额。
- WAF 不防御所有攻击；HTTP server 在进入 handler 前拒绝的连接不计入访问流。固定窗口限速、队列写入和规则检测的容量需按部署业务验证。服务健康探测不自动替换上游。
- 数据库单节点，备份恢复与双 API 演练不等于 PostgreSQL 自动故障切换、跨机房容灾或约定生产 SLA。ACME 签发、公共域名证书、生产通知地址与生产数据恢复需由部署方提供实际资源。
- 标准镜像构建未因磁盘限制重复消耗空间；已提供并验证不新增应用镜像层的运行方案。新模板、通用任意配置语义、补丁安装和专业取证不以现有三个模板冒充实现。
