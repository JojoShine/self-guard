## 真实数据库验证

真实审计先由Agent转换，再通过隔离API入库；合成标准JSON样本仅验证六引擎平台契约，不替代厂商实库。

| 实际环境 | 验证结果与边界 |
| --- | --- |
| MySQL 5.7.44、8.4.7 | 实际连接、测试表读写及认证失败；各1条真实认证事件通过原生日志转换。Community实例不含Enterprise Audit插件，行为审计插件JSON另有格式测试，未宣称实库插件验收。 |
| PostgreSQL 14、17 + 官方pgAudit | 实际DDL、读写、删除和认证失败；14 CSV、17 CSV、17 jsonlog各9条真实事件。pgAudit操作记录不被当成执行成功证明。 |
| Oracle XE 11.2.0.2.0 | 传统审计只读导出模板实测；6条真实记录，包含实例库名、稳定事件标识和会话；不导出SQL_TEXT。 |
| SQL Server 2022 16.0.4305.5 | Developer临时实例真实审计10条，包含登录、读写、DDL和审计配置记录。按sequence_group_id+sequence_number区分事件；非登录succeeded仅表示权限检查结果。 |
| 达梦8.1.4.80 | 官方ARM镜像，临时有效试用授权；实际对象读写审计及官方dmaudtool快照转换10条。单个已关闭审计文件的SHA256+完整行序号形成事件标识，保留相同内容多次操作；时区需明确核实。 |
| Oracle 12c及以上、金仓 | 用户已同意暂缓实库验收。Oracle统一审计导出模板及两引擎标准JSON契约保留；Oracle新版本原生差异与金仓原生适配仍需介质后验证。 |

脱敏验证证据保存在本机 `.artifacts/results/security-foundations/`，包括版本、审计元数据、转换结果与浏览器截图；该目录不提交。原生导出方法见[采集说明](../services/agent/audit-exports/README.md)。

## 运行与验收边界

- 本地数据库新增迁移前已备份，并在临时库恢复核验；隔离schema执行迁移及接口闭环，结束后删除临时schema。
- 审计存储有100000条保护上限，可由管理员清理到期记录；达到上限时拒绝新批次并保留Agent队列，已确认事件的重放仍可确认。未宣称无限留存。
- 处理要求中的展示脱敏、导出审批、建议留存天数作为可引用治理定义保存；数据库侧执行器未接入时明确显示未执行。
- 新Agent已构建与测试，未自动替换现网Agent。需要新版能力的主机必须通过现有发布/安装流程更新。
- 发现当前基于监听/连接观察；不把一次连接解释为资产归属或完整业务行为画像。金仓和Oracle12c实库介质到位后继续验收。
