# 安全分域基础实施记录

日期：2026-11-05。依据：[业务规划](网络安全与数据安全业务重构规划评审稿.md)和[本阶段计划](superpowers/plans/2026-11-05-security-domain-foundation.md)。

## 已实现

- Finding 增加 `securityDomain`，取值 NETWORK、DATA、UNCLASSIFIED；新增向前兼容迁移与查询索引。
- 明确来源 vulnerability、active-scan、agent-fim 归网络；database-security 归数据。Agent 数据库检测使用服务端加载的规则配置归类，不从证据文字、自报类型或实例关联直接猜测。数据库组件 CVE 仍归网络。
- 旧数据只按明确来源回填，其余保留待分域；不删除旧记录，不修改主键、去重键、状态和关联。
- 重放保留已知领域，不被旧客户端降级为未知；原未知发现可以由明确依据补足归属，原有重开和次数逻辑保留。
- `/findings` 与 `/discoveries` 支持可选 `securityDomain` 筛选。枚举非法值报错；通用列表中不支持领域筛选的资源明确拒绝，避免静默忽略。
- 发现汇总额外返回主领域及参与领域集合；混合调查可按任一关联领域查到，不复制调查。无关联发现的旧调查保留待分域。

这是归属标签和查询过滤，不是新增领域专属角色或授权体系。既有资产/实例权限继续生效；后续菜单、统计、报告和领域授权要统一接入，不能只依赖前端筛选。

## 复核修正

复核指出：既有调查授权只检查关联发现的主机，发现本身却按实例范围检查；新增调查领域集合可能泄露“主机可见、实例不可见”的发现归属。已加入真实临时库回归，先确认失败，再让调查所有关联发现复用 `resourceWhere(...,'findings')` 的完整授权条件。含不可见发现的调查整体不对该用户开放，防止通过领域集合、筛选命中或数量获知信息。

## 有效访问与正文证据实施

访问行为记录、采集覆盖与探针位于数据安全的分类与审计。既有主机流量摘要位于网络安全；两者提供关联入口，数据库审计也可跳转有效访问记录。完整请求响应可分段查看、按独立权限一次下载整份报文；过期、缺失或部分记录不显示为完整下载。

控制面新增显式观察源、来源凭据、普通访问索引、分类/规则快照和加密证据对象。普通成功、认证失败、权限拒绝和执行错误不依赖告警入库，命中规则再另行生成数据安全告警。对象元信息写入既有数据目录；未知最终用户、PostgreSQL未映射关系OID和未解析协议不推断为已知。HTTP401/403本身只作为接口错误，不代替数据库认证或授权结果。

正文按捕获时间滚动7天，晚到不续期；平台与主机队列均加密，持久化确认绑定事件/方向/顺序/校验后才清理本地字节。正文读取和导出独立授权，受主机与实例范围交集约束并留审计。存储管理增加有效访问行数、索引期限与正文配额；默认100000条、30天、1GiB，可按实际规模配置。索引自动清理沿用现有开关，正文到期清理始终执行。部署文件增加独立持久目录，正文未加入普通长期备份。

探针作为独立附属进程沿用基础Agent身份；持续抓取、解码/上传、离线清理分别运行，抓取器不持有平台凭据。附属进程不会重复认领资产。安装器和支持矩阵见 [有效访问探针说明](../services/access-probe/README.md)。本次只更新本地实现、预览和发行文件，未对生产主机启用采集。

已通过的实际合成业务验收：HTTP两次相同请求为两条记录，PCAP重放不重复；HTTP、MySQL8.4.7、PostgreSQL14、Redis7.4的262144字节真实返回从平台分段完整还原；成功、执行错误、普通记录和分类告警可分别核验。Go持续抓取跨越30秒后仍保存新访问，内核丢包为零。浏览器验证覆盖桌面、390px、筛选、源钻取、原文主动读取/隐藏及多分段整份响应下载。

TLS采用独立只读uprobe，不采用进程内预加载。内核先校验批准的socket端点后读取SSL返回缓冲；固定PID、启动标识、UID、程序和库指纹。已在Linux ARM64、动态OpenSSL3、TLS1.3、HTTP1.1组合实测：两次独立访问及262144字节二进制响应完整还原，未批准端口被排除，停止独立观察进程后业务继续成功；最终二进制复测通过。单次SSL调用预算16KiB，其他组合不能据此声称可读明文。Oracle/SQLServer/达梦/金仓的新线协议与未评审TLS组合仍明确为覆盖缺口，沿用已有原生/标准审计接入，不将格式接入当作完整原生协议支持。

最终全量API回归为311通过、11失败、31跳过（353项），未列为全绿。8项依赖本机未提供的原生扫描/规则验证程序，1项缺任务签名根环境，另有原有目标下载URL重复路径及SSH引导断言；本次定向用例及真实临时库检查另行通过。前端最终156项/46文件通过，类型与生产构建通过；真实systemd初始化环境不在当前工具镜像中，服务隔离契约及直接常驻命令已验证，未宣称所有发行版服务安装均已验收。
