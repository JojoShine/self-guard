# 通用网络安全扫描：规则库与统一操作

用户已纠正并要求继续实施：软件品牌仅是举例，不能按品牌堆菜单。沿用现有通用组件清单、官方适用库、HTTP/TCP/TLS范围控制、额度、计划、风险与处置；撤下独立中间件目录入口。

采用一个可版本化的通用检测规则目录，完整登记官方ProjectDiscovery nuclei-templates，按编号/CVE/分类/兼容状态检索。目录收录与可以执行分开，完整来源、许可、摘要和未适配原因可查。同步不改变已有计划、批准或发起扫描。管理员维护库与启用规则，日常用户选择目标和通用检测范围。

广泛规则的条件判断复用固定版本Nuclei原生引擎，不继续逐项重写DSL。第一执行配置严格限定独立、无状态、GET/HEAD单请求响应检查：现有受控HTTP引擎完成所有网络请求，原生引擎仅离线判断这一响应。拒绝多请求依赖、原始报文、代码、浏览器、OAST、外部网络函数及未支持语义，不丢弃条件或伪称全兼容。选择范围由结构能力决定，不由软件品牌决定。HTTP路径仍按原授权规则；其他配置保留明确缺口，后续扩展执行配置而不是新增品牌页面。

原生配置保留原件及其SHA-256，形成单请求规范化执行模板并分别计算摘要。纯响应匹配才可执行；CLI配置和环境隔离、禁更新/遥测/交互回连，进程/输出/文件限额、临时响应文件权限与清理必须落实。复用既有请求额度、固定地址、批准路径及撤销检查，Nuclei不自行扫描网络目标。

本地模板继续沿用正反样本校验和批准。官方库规则使用独立、明确标记的原生编译校验和管理员批量批准，不能把编译当正反样本或实际命中；任何变更清除批准，固定原件、规范化模板、引擎及来源摘要。普通扫描默认选用当前已批准且协议兼容的规则，预览冻结准确规则集；库更新不扩大旧计划。

没有业务Web目标，只做自有隔离HTTP正反及范围拒绝、库完整入库和广泛规则编译验收。远端PostgreSQL不重启、SQL预留、原collector不升级。保留所有既有未提交改动，不提交密钥，不声称全部CVE均可检测。
