# 可操作体验空间
用户要求体验账号不只读。保留现有正常登录和生产权限边界，为保留体验身份增加独立、按登录会话隔离的可写体验空间。

选择：专用体验工作流，复用当前 UI 组件、数据库 Setting 和 SQL 报文解析器。直接提升公共账号权限会开放真实资源；单独部署完整租户与外部执行环境涉及额外运维和网络隔离，因此本次采用有边界的样例工作流。

用户可以添加/删除演示资产、创建/执行样例版本检查、更新问题处置状态、解析 SQL 样例和重置当前空间。配置和结果实际写入服务端；检查仅对预设样例执行确定性版本规则，不访问目标，不称作真实网络漏洞扫描。SQL 为报文解析器处理的合成样例，不连接生产数据库。所有界面明确标注。

命名空间只从已认证 Bearer 会话哈希派生，忽略任何用户指定空间标识；非体验身份不得调用。原资产、扫描、SSH、运维、SQL证据授权保持不变。会话隔离、8小时到期、500空间上限、每空间20资产/10任务/40问题/5SQL样例；事务锁和版本控制防并发丢写。重置仅删除本会话空间，不改共享样例和真实表。
