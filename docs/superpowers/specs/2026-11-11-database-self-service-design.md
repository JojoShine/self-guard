# 数据库自助接入与多引擎采集

目标：用户自行添加数据库后，在同一实例内完成能力确认、连接验证、运行指标和审计接入，直接查看实际记录。包含PostgreSQL、MySQL、Oracle、Redis、达梦、人大金仓、海量Vastbase；未知产品版本必须实测识别，不因协议兼容标为已验收。

复用实例、采集主机授权、运行监控、审计事件、原文加密与现有API。保存实例立即进入接入验收。运行指标、连接审计、语句/命令原文分别显示配置与实际收到状态；Redis显示命令，不伪称SQL。维护和普通只读用户入口区别保留。

原PostgreSQL14+运行监控及CSV SQL保留兼容。其他引擎使用固定只读系统统计查询和真实身份识别；原生驱动确需依赖时固定版本。安全连接验证、加密凭据绑定、超时、并发及历史预算保持。不能可靠读取的字段显示缺口，不能填零；专有介质不足时明确未完成实库验收。

SQL/命令审计仅显式选择的采集来源保留原文，原元数据来源不改变。沿用独立权限、加密和7天保留；接收到查询不等同执行成功，慢日志不等同全量审计。禁止自动开启数据库审计、重启、自动授予权限或记录凭据。

不修改121.196.245.95数据库、不升级已暂停的业务collector、不对业务制造故障。实际检查仅隔离实例、临时schema、只读请求或合成协议样本；生产部署、各专有产品版本验收如实记录。
