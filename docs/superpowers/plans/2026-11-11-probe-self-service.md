# 探针远程交付与监控自助操作

目标：用户在平台自助检查、远程安装和停止网络协议/入侵检测及数据库访问审计探针；明确基础Agent、连接摘要、独立协议/访问探针状态，修复fusectl导致资源部分指标误报。

用户已明确两类都需要，无需重复征求常规实现许可。保留全部原数据/身份，宿主PostgreSQL及其SQL日志仍不重启、不改动。此轮独立模块按dispatching-parallel-agents指引分工，发布与服务器变更仅由主代理顺序执行。

设计选择：复用已有主机管理连接、固定SSH主机密钥、AssetRemoteJob执行队列和来源权限；不建立另一套安装账户/SSH通道。探针以已验证平台发行镜像内的双架构固定制品部署，SSH传输及远端摘要检查，来源专用凭据仅在受保护通道配置，不能出现在接口任务列表、日志或审计中。网络探针安装独立旁路引擎与桥接器，不改防火墙和业务流转发；数据库探针复用已有--install-config和已授权端点。不能把服务启动等同于真实采集验收。
