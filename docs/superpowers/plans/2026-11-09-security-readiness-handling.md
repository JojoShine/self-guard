## Global Constraints

- 在当前工作区增量修改，保留已有大量未提交功能；不提交、不恢复WAF、审批编排或自动执行。
- 采集授权、近期上报、有效数据和检测结果分别展示，不计算虚假的综合安全分。
- 读写沿用主机/实例权限；汇总不返回凭据、正文或不在授权范围的计数。
- 复用已有状态、审计和通知，新增接口/可选字段保持旧调用兼容。
- 不自动安装远端组件、发起业务扫描、发送外部通知、修改业务数据库权限或恢复暂停的主机升级。

## Review Focus

- 有主机权限但无实例权限时，数据来源与记录不能通过汇总泄漏。
- 离线、无有效事件、配置未确认及回放不等于持续检测正常。
- 待复查的风险和告警必须有实际复查依据，不能直接在状态表单中关闭。
- 旧客户端仍可使用原告警终态；新界面必须引导处理后复查，并明确人工登记不代表自动扫描。
- 并发或陈旧表单不得覆盖他人刚完成的处置；时间清空、失败重试和只读角色行为一致。
