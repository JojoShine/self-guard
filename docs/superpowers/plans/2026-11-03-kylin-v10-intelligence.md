# 银河麒麟V10漏洞来源与扫描实施计划

目标：用户主要使用银河麒麟高级服务器V10。复用现有官方来源、完整快照、RPM比较器和软件清单扫描；补齐官方UpdateInfo接入、Agent识别和前端配置。当前分支原地连续执行，保留已有变更，不提交/推送。

裁定：按官方V10SP1、V10SP2、V10SP3、V10SP3-2403分支及x86_64/aarch64适配；其他专用版不推定等价。需要明确高级服务器产品、SP分支、架构、RPM完整EVR；缺失时标无法完整判断。官方repomd中压缩/解压SHA256均核验，原始XML保存；不套用RHEL/openEuler补丁，不修改主机软件。

- [x] 1. 来源与解析：安全XML解析、尺寸/实体/校验限制；KYLIN提供方、固定官方URL、分支架构配置，复用同步与失败保留机制。验证真实官方XML与损坏/越界输入。
- [x] 2. 判定：Kylin独立生态、SP隔离、包架构与epoch/version/release、noarch规则、CVE/KEV关联、历史快照证据；未知系统/桌面版/旧Agent不误判。先失败测试再实现。
- [x] 3. Agent：补充产品与SP信息的只读采集、限定文件与有界解析、RPM完整版本延用；Go相关回归。
- [x] 4. 界面与初始化：来源目录及配置选项、范围与覆盖边界说明；创建并同步真实官方V10来源，不默认假设用户所有主机均为SP3。
- [x] 5. 验收：API/Web构建及定向回归，真实源同步、临时数据空间HTTP扫描闭环和页面核对；独立只读复核；记录官方源与真实麒麟主机验收的差别。

依赖裁定：官方数据为XML，现有项目没有XML解析器；允许新增一个严格、禁用DTD/实体的流式XML解析依赖，避免手写不完整XML解析或额外部署Python/Go解析进程。尽量不修改数据库结构，沿用provider字符串、config/metadata JSON和现有原件存储。

验收：8组真实官方来源共7508条范围内公告已初始化，每日同步；API情报/扫描回归117项、Web131项、Agent全量Go回归及API/Web构建通过；隔离HTTP和桌面/窄屏浏览器通过。独立复核的多CVE别名串联、缺RPM release均先失败后修正。KYSA保留公告身份，CVE走独立上游上下文，同时补齐CVE搜索。现场麒麟主机和新版Agent实际部署尚未验收，详细记录见`docs/银河麒麟V10漏洞适配验收.md`。
