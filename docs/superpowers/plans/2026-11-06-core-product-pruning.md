# 核心安全产品裁剪实施计划

> 使用 superpowers:executing-plans 原生连续执行。用户已要求按讨论方案执行，无需重复方案审批。不提交、不部署，不改生产或删除历史数据。

**Goal:** 将菜单、概览、配置、详情及指南收敛到资产、网络检测和数据访问审计。
**Architecture:** 复用页面与接口，导航区分日常入口、就近配置和已退出模块；后台契约不变。
**Tech Stack:** React、TypeScript、Ant Design、Vitest。
**Spec:** ../specs/2026-11-06-core-product-pruning-design.md

## Global Constraints
- 保留既有数据和服务端权限；不因隐藏菜单取消授权校验。
- 不新增WAF产品能力或自动处置，不停用外部服务。
- 不混淆原生审计与旁路请求响应；沿用正文独立权限和7天期限。
- 来源与更新入口必须仍可找到；配置不再独立业务中心。

## Review Focus
1. 旧WAF/修复链接不展示可执行旧流程，也不误跳其他数据。
2. 资产、实例、访问记录之间的筛选参数与来源标签仍保留。
3. 窄屏菜单、表格及详情不横向撑破页面；键盘和返回路径可用。
4. 详情/概览/指南不继续引导审批修复，简单状态与备注仍可用。
5. 概览真实请求遵守用户范围，失败显示错误而非伪造零值。
