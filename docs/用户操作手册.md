# Self Guard 初版操作手册

运行和检查方式见 [运行与验收说明](运行与验收说明.md)，当前验证范围见 [验收矩阵](验收矩阵.md)。开发界面为 `http://127.0.0.1:5180`，API 为 `http://127.0.0.1:4010/api`。管理员邮箱和随机密码保存在私有 `.env`；不要将密码、Token、配置秘密或私钥写入调查备注和公开文件。

## 系统内操作指南

登录后点击右上角“操作指南”，进入独立的 Markdown 阅读页。该页面不显示系统左侧菜单或业务卡片，使用左侧文档目录与右侧Markdown正文。点击目录定位章节；窄屏下目录位于正文上方，全部内容按章节连续阅读。顶栏“返回系统”回到进入前的页面并保留查询条件；直接打开或刷新指南后，返回入口默认进入工作台。

指南保留当前全部43个菜单入口，但正文按实际工作过程组织：先理解资产、风险、告警、事件与任务的关系，再完成接入、研判、检测、修复、Web防护、报告和平台管理。各功能解释数据从哪里来、输入参数会改变什么、不同状态应怎样处理，并给出字段示例、结果判断和下一步路径。

“完成第一轮操作”使用首次接入、文件权限风险修复和站点防护三条实际路径。功能章节补充模板适用条件、任务状态对照、WAF观察/阻断与误报处理、报告日期口径、权限范围和存储限制等说明。章节目录可独立展开，随正文阅读高亮当前小节；点击模块文字链接才会返回业务页面。可以使用浏览器查找（Ctrl+F / ⌘F）定位关键词。

Markdown 正文源文件为 [系统操作指南](../apps/web/src/content/operation-guide.md)，页面直接渲染该文件，修改内容无需同步另一份结构化数据。

## 工作台与查询

工作台显示授权范围内的资产、风险、告警、事件、任务和 WAF 安全事件。点击指标、图表或待办记录直接进入对应菜单；进入业务列表后按需筛选，再点击标题打开详情。个人工作台按当前负责人和审批策略统计，区分心跳在线、超时、从未上报与归档资产。进入后的列表按当前时间查询，业务变更或心跳经过边界时，数量可能与先前快照不同。

在线 WAF 请求量是最近 90 秒有心跳节点的当前进程累计计数，节点重启会重置；安全事件数是平台已接收记录，二者不是同一统计口径。明细显示节点版本、进程开始时间、心跳及受控计数。

列表支持文本、类型、状态、严重程度、业务、负责人、资产和 UTC 创建日期组合查询及稳定排序。保存视图按当前用户隔离存于浏览器；复制查询链接可保留筛选，刷新和浏览器返回也保留。导出使用相同筛选与顺序，最多 10000 条并显式标记截断。风险/告警列表可批量已读和分派，逐项显示结果；混合“全部发现”不强行应用统一状态操作。

正式列表默认每页 15 条，可切换 15、30、50、100 条；修改筛选或每页数量后从第一页查看。带“查询”或“生成”按钮的表单需要提交后才应用新条件，翻页沿用最后提交的条件。首页待办等摘要保留有限条预览。

## 权限

ADMIN、ANALYST、OPERATOR、VIEWER 由服务端校验。组织审批策略可以单独指定审批角色及是否允许自批。拥有审批权不自动获得修改用户或全局策略的权限。

管理员在用户详情配置业务和显式资产授权，两者取并集。开启范围限制且未授权任何业务/资产时，没有资产访问权。证据读取独立控制，关闭后证据、任务参数/结果、清单、附件和敏感内容不可读；后台通知与导出遵循同样的权限。数据范围修改在现有会话内生效。管理员保留全局管理权。

## 资产、风险与事件

资产以持久身份注册，不用 IP 作为唯一身份。详情显示清单、采集完整性、诊断、关联发现/任务和资产变更历史。缺少包管理器或 systemd 等工具时，采集显示不完整，不能解释为没有风险。

归档保留历史并禁止 Agent 上报与领任务；存在执行中或结果未知任务时拒绝归档。清单内容和业务字段变化会形成差异记录，普通心跳诊断变化不反复刷历史。

风险可确认、分派、延期、标为误报或接受。延期需原因；风险接受需原因和到期时间，到期重新开放。已关闭问题再次出现会重开。告警的“已读”只代表查看状态，可关联风险或加入事件。

事件支持多个风险/告警、受影响资产、处置任务、事件类型、调查备注、附件与剩余风险说明。验证和结案按独立状态推进，结案不自动关闭关联风险。统一时间线和关联入口位于详情；记录过多时接口有明确返回上限。

附件最大 1 MiB，每对象最多 50 个、合计 20 MiB。下载遵循对象与证据权限，默认作为文件下载，不在页面执行上传内容。

## 检测与规则

配置基线、日志和 FIM 由 Agent 周期执行；漏洞检测由服务端按上报清单匹配，可手动或定时运行。结果区分命中、未命中和无法完整判定。

“漏洞数据源”接入受信 OSV HTTPS 源，默认仅允许官方单条公告接口。界面显示同步状态、失败/重试、来源和覆盖缺口。Debian/Ubuntu 版本范围与精确版本有实际比较逻辑，其他生态不以静默忽略代替覆盖说明。

在“规则范围与样本”中配置资产、业务、标签；多个维度须同时满足，每个维度内任一匹配。基线豁免限定资产，可加精确路径，必须有原因和到期时间。到期后继续检测，豁免不自动关闭已有发现。受限用户不能查看其他资产的全局豁免上下文。

基线和日志样本测试调用实际 Agent 的只读引擎，漏洞样本调用实际匹配逻辑，不读取主机文件、不修改配置、不创建发现。FIM 需要前后文件状态，使用真实采集验证，不提供会造成误导的单次静态样本按钮。规则修改、启停及恢复均形成版本和审计。

## 修复、审批与验证

模板目录包含 FILE_PERMISSION、CONFIG_VALUE、SERVICE_STATE 三个固定 v1 模板，展开查看参数、影响、前置检查、执行、验证和恢复步骤。管理员停用模板后不能新建或领取该模板任务；已经领取的任务按原批准方案执行，恢复和只读核对仍可进行。

创建任务需目标资产，可关联该资产的风险。审批详情展示模板版本、批准参数、影响、前置条件、执行窗口和恢复步骤。前置条件列表是执行要求，不能把它当作目标主机已经通过检查。参数和目标创建后不可变；修改执行窗口会清除原审批，重新进入待审批。

文件路径须在 Agent 本地允许根目录，拒绝符号链接、多硬链接和非普通文件。CONFIG_VALUE 仅处理 64 KiB 内恰好出现一次的字面 KEY=VALUE，要求旧值精确匹配，不支持任意配置语言。SERVICE_STATE 仅启动/停止明确列出的 systemd 单元，须匹配旧状态，可能影响业务。可选 healthService 也必须在本地白名单，通过只读 active 检查，不会自动重启应用。

执行成功先进入 VERIFYING，再生成独立 VERIFY_READ，重新打开目标检查。变更复验通过不等于所有关联风险都已消除：只有与原检测依据一致的权限/服务基线可以自动关闭；无关软件漏洞、导入风险及不能从秘密证据绑定的配置风险仍待安全复测。授权分析员应检查原始检测依据后提交独立复测结论。

回滚是独立审批任务，引用原任务的私有状态/备份；核对目标仍处于原变更结果后才恢复，再独立验证。回滚通过后原任务标记 ROLLED_BACK，关联风险重新开放。取消和停止批次不撤回执行中任务，也不回滚已经完成的变更。

1–100 个待审批任务可组成批次，各任务仍需独立审批；串行等待前一项验证。发生失败或 UNKNOWN 按策略停止后续任务。UNKNOWN 表示实际结果未核对，不能直接重新执行。配置/服务/升级恢复标记存在时先核对主机状态、备份和作业，再按恢复手册处理。

## 采集权限、执行器与升级

推荐使用非特权采集器及独立 root 执行器，部署样例和命令见 [Agent README](../services/agent/README.md)。执行器使用 Unix socket、调用用户校验、服务端签名、资产/期限绑定、本地白名单和私有防重记录；采集器没有本地修改权限时也不会回退提权。

执行器仅导出结果验签公钥，私钥保留在受保护状态目录。管理员在资产详情绑定该公钥后，缺失/无效签名只能进入 UNKNOWN，不能关闭风险。部署者需配置服务端任务签名私钥并向执行器分发对应公钥。

“Agent 灰度升级”接收受信 HTTPS 来源的发布签名包。发布前设置明确的允许来源和发布公钥；未配置时远程升级不可用。校验准确 manifest 字节、摘要、大小、架构、序列和有效期，先金丝雀再分批；失败暂停后续。

升级写入受控安装槽、自检、保留恢复记录；由 supervisor 在退出 75 后重启新版本，再核对新进程心跳。分离执行器负责下载与安装，分别核对任务签名和发布签名。单独命令行暂存只代表磁盘程序已更新，必须重启运行进程。恢复命令、目录权限和最高序列保护见组件手册；不能以回滚清除防重放序列。

## Web 防护

新增站点配置精确域名、上游、策略及观察/阻断模式。上游健康显示状态和检查时间，不自动切换路由。先用自己的合法流量和攻击样本通过在线只读测试，再启用阻断。

支持 URL、请求头、有界表单/JSON、SQLi/XSS/路径穿越/命令特征、CIDR/路径/方法控制，以及站点/客户端/精确路径限速。例外限定 ruleId、路径及可选参数。基础启发式防护不覆盖所有攻击，不能代替应用修复。

证书页面校验域名、有效期及私钥匹配，加密保存私钥，可轮换和停用。节点显式启用远程证书后热加载，保留私有离线缓存；本地证书清单优先。未知 SNI 或到期证书拒绝握手。ACME 签发和公共证书申请由部署方处理。

“访问日志”展示最近 1024 条快照；“遥测记录”中的 ACCESS 为持久队列同步的访问流。路径、参数和凭据脱敏，进入 HTTP handler 前拒绝的请求不计入。攻击事件另有持久 outbox 并汇入安全中心。达到队列/中心存储上限时查看未确认数量与写失败计数，不把有界系统当无限归档。

## 报告、通知与保留

报告按 UTC 创建日期和业务筛选，处置结果表示该创建范围内记录的当前状态，不是当天完成量。CSV、JSON、自包含 HTML 及打印采用最后实际生成的报告筛选，修改尚未提交的表单不改变导出标签；导出有审计。

站内通知按个人订阅与权限后台同步，也可手动刷新。外部通知仅支持无嵌入凭据的 HTTPS webhook，加密保存地址和签名密钥；稳定投递 ID、签名及退避重试供接收方去重。投递前再次检查当前用户与资源权限。已有通知是生成时快照，操作前看对象当前状态。

数据保留可预览到期数量后显式清理，审计至少保留 30 天。另有日志类行数上限和可选自动清理，默认不开启自动清理；开启后每小时按已保存策略清理到期记录并审计。业务资产/问题/事件/任务不在自动删除范围。

新入库遥测采用当时设置的有效期，既有记录保留原有效期；缩短策略后自动清理可能更早清除到期范围。数据库字节数含索引和空闲页，行数限制不是磁盘硬配额。保存上限不会删除未到期记录，达到上限拒收新增，组件保留未确认队列直到恢复。

## 运维与恢复

定期备份策略配置间隔和保留数量，工作进程只清理自己创建的旧备份。定期核对备份状态并运行隔离恢复验证，恢复目标不是正在运行的数据库。加密密钥、组件私有状态、升级备份和证书材料需在受控部署备份中保留。

登录失败限速保存在数据库，重启 API 不清零。排查 UNKNOWN、恢复标记、无心跳、策略版本落后或写失败时先核对实际状态，避免重复变更。双 API 就绪与故障切换配置、TLS、密钥轮换及复现命令见运行说明；它们不等于数据库自动切换或生产 SLA。

新增 Agent 安装任务、SSH 批量安装和发行版本页签，以及 Web 防护下的防护规则库候选导入/兼容报告。详细输入、判断与恢复路径以系统内 Markdown 指南为准，完成度以 [Agent、WAF 与扫描实施记录](implementation/Agent-WAF-扫描实施记录.md) 的实际证据为准。
