## 支持条件

当前自动接入要求 Linux、Agent 0.4.9、预装 Docker、固定摘要且架构匹配的自研 WAF 镜像，以及单一域名/根 location/HTTP 上游的真实 Nginx 配置文件。复杂配置不自动改写。健康路径要求无副作用、稳定2xx且正文不超过64 KiB；HTTPS入口正常校验证书。

开发环境已装载本次自研 WAF 镜像。其他 Linux 主机须先交付对应架构的镜像；管理服务 HOST_WAF_IMAGE 指向固定摘要。当前没有自动安装 Docker 或向外部镜像仓库发布制品。本机 Agent 安装完成与 WAF 入口验收分别计状态。

默认捕获是按授权时段和过滤范围观察实际报文，不是全流量存储、HTTPS解密或自动阻断。IP分片和IPv6扩展链不推断传输端口。捕获摘要按最近一次结果保存，本地证据目录由运维保留。
