# 资产远程管理与捕获交互调整

用户目标：资产可登记 root SSH 账号密码，平台直接执行一次流量捕获，不要求每次人工登录主机；资产中心的新增、配置和确认均在独立右侧面板或居中弹窗中完成。

实现边界：复用固定 Agent 0.4.9 捕获命令与现有 SSH 安装服务。管理连接单独加密存储，不作为普通采集器权限，不在资产、审计或错误中回显密码。连接到登记的明确 IP，使用用户核实的 SSH 主机公钥；不自动接受未知密钥。界面说明可从云主机控制台取得主机公钥，不要求把登录密码写入命令。默认 root；服务端始终验证权限与资产范围。

1. 新增管理连接和持久捕获任务；验证保存与权限、凭据不回显和任务互斥。
2. 平台通过受保护 SSH 通道发送捕获配置，在目标执行有界捕获，读取摘要并由目标已有 Agent 上报，核对与当前资产身份一致才完成；服务重启或连接中断标为结果待核对，禁止自动重复执行。
3. 增加连接测试与网卡选项；捕获按钮直接发起任务并在同一个面板显示状态与结果，手动下载仅为备用方式。
4. 已保存连接可用于单资产 Agent 安装，复用现有签名版本、安装票据、服务验收及 SSH 批次记录。
5. 安装创建、发行确认、批次详情与确认改为独立面板；关闭/切换页面清理敏感输入与过期请求。正文帮助同步更新。

验证：小范围单元与独立数据库 HTTP 测试；受控本地 SSH 测试密码认证、主机密钥拒绝和命令边界；1440px/390px界面交互；新增迁移前做独立备份与恢复核对，不初始化或删除业务数据。
