# 平台统一接入与 HTTP 支持

日期：2026-11-01。

## 解决的问题

远程安装任务已经在 SSH 批次中失败，但安装授权记录仍为 WAITING，列表没有自动刷新。普通用户又被要求判断并填写平台地址，容易误填资产或站点域名。

## 实现

- 平台统一维护经过身份验证的接入入口，支持 HTTP 和 HTTPS。部署可提供 `AGENT_PLATFORM_URL`，HTTPS 自建 CA 可提供 `AGENT_PLATFORM_CA_PEM`；管理员也可在“资产中心 → 采集与接入 → 平台接入设置”维护一次。
- 非本机地址访问平台时，管理员打开安装表单会尝试验证并采用当前入口；普通操作人不填写地址。地址必须返回当前平台的公开身份，不能误连到其他平台。缺少配置时不允许创建安装任务。
- 单机安装、SSH 批量安装、列表远程安装及发行版本升级入口共用该配置。HTTP适合受信网络；HTTPS仍校验证书，不自动降级。
- 远程安装在发送安装票据下载程序之前，先无凭据检查公开平台就绪接口。错误域名、404、证书、DNS、超时、摘要与执行阶段以固定文本解释，不保存任意远程输出。
- SSH 执行状态同步到安装记录，并修复既有失败批次留下的 WAITING。成功、撤销、恢复状态不会被覆盖；连接中断保留 UNKNOWN，不自动重复安装。安装列表、打开的详情及批次目标每5秒自动更新运行中状态。
- 原截图任务9bd2a268已根据持久失败记录修正为FAILED，记录了公开接口返回404的只读诊断与审计，没有重试目标主机。

## Agent 与 WAF

Agent **0.4.10 / 序列41**，AMD64和ARM64签名灰度发行，原始程序、tar.gz、DEB、RPM共8种下载已逐字节核对；旧发行和稳定默认版本未覆盖。

HTTP安装明确持久化AllowHTTP；不使用Development模式代替生产支持。采集器、执行器与恢复连接保留同一传输选择，离线准备和受控下载兼容该协议。签名、摘要、目标授权、精确来源及协议绑定继续校验，不跟随重定向。HTTP安装必须选择0.4.10及以上，界面禁用旧版本且服务端再次检查。

WAF通过独立的WAF_ALLOW_HTTP明确选择HTTP管理通道；不改变站点业务入口的HTTP/HTTPS。新本地镜像selfguard-waf:http-platform固定摘要为sha256:f110b4ef86cd6b81b9e282d6bc17454b30d2bada7aa96790c6df8528857d5bc0，已用于本地后续同机接入计划。目标仍需交付架构匹配的固定镜像；既有运行节点没有被自动替换。

## 验证与边界

- 独立数据库验证HTTP/HTTPS入口及CA、当前平台身份匹配、无配置阻止排队、历史失败同步、成功/撤销保留和重试不自动执行。
- 签名Agent0.4.10实际通过非回环HTTP地址注册并上报主机清单，AllowHTTP=true、Development=false；仅写入独立验收库。
- Agent完整race测试通过，WAF管理连接测试及镜像内完整PCRE2测试通过；前后端构建通过。
- 1440px/390px验证HTTP自动配置、新版本选择、安装入口、捕获路径及自动进度更新。操作指南已同步。
- 当前平台统一入口仍需通过实际部署地址完成验证。HTTP支持不等于localhost会变成云主机可访问的地址，错误站点域名不会被接受；未把原失败主机标为安装成功或自动重装。
