# 数据安全基础规则与统一交互实施计划

依据用户已确认要求连续实现，不使用子代理。复用自研Agent、检测、采集、WAF及既有审批能力，不开启未授权的主动攻击，不默认执行封禁或修改数据库配置。

## 范围与验收

1. **完整字段表**：原始记录默认可见，以分页字段表展示已留存字段、嵌套对象和数组；保留原字段名及复制入口。未知字段不得静默丢弃，缺失/脱敏/权限隐藏如实说明。验证深层结构、转义、空值、零值及原有证据展示。
2. **策略中心弹层**：创建、编辑、范围/身份调整、样本结果和运行详情统一右侧抽屉或居中弹窗。原列表保持筛选及分页，父子详情在同一层级切换；抽屉内显示错误并保留重试。复用已有授权和运行门禁。
3. **数据安全基础目录**：提供可启用、可自定义的基础规则及业务说明。先覆盖数据库失败登录聚合、MySQL强制加密、PostgreSQL TLS开关/pg_hba明文与免认证配置、凭据文件权限。数据库原生格式按官方资料实现并明确来源缺口，不用关键词次数伪装成按源识别，也不从端口或握手失败推断真实明文。
4. **真实采集与适用性**：Agent在明确授权文件范围内解析日志，记录来源、目标、账号、事件时间、依据摘要及聚合条件。新能力按Agent能力匹配；旧Agent不得把新规则当旧规则执行。配置风险、真实行为和已执行处置分别表达。
5. **追溯与留存**：请求/事件关联标识、来源及实际链路、脱敏路径与参数留存状态、规则及处置结果显式存储和展示。WAF阻断/观察与上游返回状态区分；未转发不能显示为已到达上游。敏感凭据不落原文；缺失字段不补造。
6. **交付检查**：每个模块以受影响路径定向测试推进，收口时合并构建及代表性桌面/窄屏交互。数据库有新字段时追加迁移，先做独立备份/恢复验证，保留业务数据；不重复无关长测。

## 已实现与验证（2026-11-01）

- 完整留存字段默认展示为Ant Design表格，支持嵌套对象、数组、未知字段、空值和原始JSON复制；默认15条并支持调整数量。原有权限隐藏继续生效，不还原未留存字段。
- 策略中心扫描计划、运行/目标/逐项结果、网络目标、模板导入、执行身份、情报来源与记录、规则范围/样本等改为右侧抽屉，编辑或子详情不叠加第二个父详情。规则和站点通用编辑、历史恢复使用居中弹窗。
- “策略中心 → 规则范围与样本”增加7类数据安全模板：数据库认证失败聚合、明确成功的未加密连接审计、MySQL强制安全传输、PostgreSQL TLS开关、pg_hba非加密配置、网络trust配置、凭据文件权限。
- 配置检查产生风险，实际日志行为产生告警；无法读取、缺少关键字段或超限产生覆盖提示。数据库日志使用原始时间与来源IP分组，跨采集周期持久化窗口。凭据权限只检查权限位，不读取凭据内容。基础规则只检测，不自动修改数据库或持续封禁。
- 新增data-security-v1能力协商，旧Agent不接收新规则。最终签名候选为0.4.4（序号35、canary），提供AMD64/ARM64原始程序、tar.gz、deb和rpm，八种下载逐字节核对通过。0.4.2因真实PostgreSQL数字端口兼容问题已撤回；0.4.3仅保留本地构建，最终0.4.4补齐正常运行日志分类。未创建业务主机安装或升级任务。
- WAF事件与访问记录保留同一请求关联编号、直连对端、可信代理来源依据、入站加密状态、脱敏路径、参数名、请求目标摘要、处置动作及结果。访问记录另保存实际回源连接及加密状态；阻断事件不提前填写回源事实。
- 持久访问队列直接写入完整访问记录，按记录编号去重；访问快照仍是有界近期数据。事件详情可在当前抽屉查看同一请求访问结果并返回。当前处置明确标识为本次请求阻断/观察，不虚构持续封禁和解封历史。
- 追加迁移20261101180000_request_trace，仅给WafEvent/WafAccess增加可空context字段。数据库备份已独立恢复验证，9项业务计数保持不变，1766条漏洞资料的完整内容摘要一致；迁移数31→32。
- 系统操作指南已同步接入步骤、格式、结果位置、检测边界与留存预算。
