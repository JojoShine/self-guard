## Cookie v0 语义

现有字段构建器要求引号配对并去除外层引号，使原始 `921250` 样本提前报字段不完整，尚未进入对应规则。主流 ModSecurity v0 语义按分号分隔并保留引号字节；不能误做 RFC2109 的带引号字符串解析。

以下回归已在独立长测结束及全部夹具恢复后先复现失败，再实现：

1. 保留引号、重复 Cookie、仅名称条目和完整原始头；允许规则直接检查这些实际字节。
2. 空名称的显式值保留在集合中参与检查，不丢弃攻击载荷。
3. 对非法名称及控制字节明确拒绝，不猜测后端如何重命名、裁剪或合并。受控的起始空白与字段内控制字节分别处理。
4. 复验原始 `921250` 和其他完整语料，明确记录所有变动；异常正文、Unicode与协议差异分别验证。
5. 只有完整竞争检查、严格CGO、全部冻结语料和实际HTTP行为验证后，才形成新的候选程序。新程序的完整性能验收不能套用旧程序摘要。

依据：[ModSecurity v0字段解析源代码](https://github.com/owasp-modsecurity/ModSecurity/blob/v2/master/apache2/msc_parsers.c)、[Cookie格式说明](https://github.com/owasp-modsecurity/ModSecurity/wiki/Reference-Manual-%28v2.x%29#seccookieformat)、[Cookie解析差异原始安全通告](https://github.com/corazawaf/coraza/security/advisories/GHSA-g4qm-m288-5cp9)。保留空名称与拒绝歧义字节是本平台明确的保护契约，不宣称与所有上游及后端解析器完全等价。

解析代码已修复并通过完整竞争与严格CGO回归。最终独立候选`waf-cookie-final-native`的SHA-256为`4a432e9b0180ca4c4f0e07ba08ac4fd70f3c9a72257ab671622bc5e96ba86a20`，正式运行程序未替换。完整2799阶段结果：2743条规则断言、10条日志断言及1条预期解析错误通过；19解析拒绝、9未完成、2规则差异、其余待验类别完整保留。逐条差分中921250/2、933100/54、941110/1、941190/3从字段不完整转为预期规则命中；941110/8含名称内空白，按本平台歧义保护契约转为未完成而非放行。该兼容差异不隐瞒，也不宣称全库通过。

## 真实 HTTP 状态断言

现有2799条工作进程语料保留规则ID、分值、诊断和失败原件，但未覆盖实际HTTP服务器响应。新增 `prepare-crs-http-status-corpus.cjs` 准备选定PL1原始状态断言，逐个核对本地官方样本SHA并保持请求字节不变；`seclang_corpus_http_test.go` 将通过真实本地HTTP监听、签名原始策略、生产时限/头部预算及固定测试上游记录状态。

冻结的上游 `tests/docker-compose.yml` 使用 DetectionOnly，原生HTTP对照因此采用观察模式；本平台检查未完整完成时仍会明确拒绝。该报告独立于原规则匹配报告，不以HTTP400证明某个规则已匹配，也不覆盖掉上游断言差异。CONNECT目标路由、HTTP解析器行为、头部合并和原生规则行为分别保留事实，差异不通过修改原预期消除。

最终候选已完成27项原始HTTP状态断言：23项一致；CONNECT目标路由1项为404而原预期200，3项Go HTTP服务器在处理器前返回505而上游预期400。报告同时记录handlerRequests，不能把服务层拒绝当作规则命中。观察模式的正式运行阈值为5，原工作进程单独规则阈值另列，未放宽正式1–100限制。结果见`crs-cookie-final-native-http.json`；这些差异及此前长测失败均保留，运行门槛关闭。
