# 同机 Web 接入与流量捕获实施计划

用户已批准实施，不使用子代理，不修改现有业务站点，不下发全局 WAF 密钥。

## 验收目标

1. Agent 提供 Linux 原生报文捕获：明确网卡、协议、端口、CIDR、时长、包数、字节和快照上限；默认仅保存连接摘要，显式授权才落地 PCAP；不解密 TLS。
2. Nginx 反向代理站点接入：只处理受支持的明确配置文件；保留入口证书和域名，转发到本机 WAF；接入前校验，原文备份，失败回退。已有 WAF 或安装程序交付的 WAF 必须实际可用，不能仅修改配置后宣称成功。
3. 平台展示真实采集结果、部署条件、状态与操作入口；使用资产级凭据限制同机 WAF 的可见站点，禁止分发全局组件凭据。
4. 更新操作指南和发布交付，针对实际 Linux 抓包及 Nginx→WAF→业务链路验证；失败场景验证恢复。

## 执行顺序和验证

- [x] 阶段一：流量捕获、报文解析和预算。先失败测试，再实现；Linux 实际环回流量验证，其他系统明确不支持。
- [x] 阶段二：Nginx 受控配置转换和接入事务。验证正常流量、阻断样本、配置失败和恢复；不执行当前主机业务变更。
- [x] 阶段三：平台配置与安装衔接、节点权限和结果展示。类型检查与相关接口测试；不覆盖业务数据。
- [x] 阶段四：指南、发行包与整体验收。按最终实际能力描述，未通过的环境不标记支持。

## 技术裁决

- 当前目录不是 Git 仓库，原地进行必要修改，不创建仓库；进度与测试证据保留在此文档和 .artifacts/results/expansion/network-onboarding。
- 用户要求不使用子代理；实现和最后审阅均在当前会话完成。
- 抓包与阻断分开：抓包不会自动赋予 WAF 接管入口的能力。普通采集服务不获得原始套接字权限。
- 第一批支持明确的 Nginx HTTP 反向代理上游；静态站点、PHP、复杂 rewrite/includes、容器网络、HTTPS 上游不得未经验证自动改写。

## 进度与证据

- 阶段一完成：范围/隐私/预算/报文解析测试；隔离 Linux NET_RAW 环回报文实测通过（capture-linux.log）。抓包由独立 root CLI 执行，普通采集器权限不变。
- 阶段二完成：真实 Nginx → 自研 WAF → 独立业务进程在 OBSERVE/BLOCK 两种模式通过，验证实际访问记录、样本命中和配置恢复；失败恢复与并发修改拒绝覆盖测试通过（linux-network-runtime.log）。
- 裁决：初版界面仅生成元数据捕获；专家 PCAP 需显式授权且只落本机。清理命令已提供，保留期限由运维已有维护计划执行，未配置清理时不能启用正文。避免为一次抓包静默安装长期 root 服务。
- 裁决：安装后接入需要目标预装 Docker 与固定摘要 WAF 镜像；发行包不自动安装 Docker、不使用浮动远程镜像。环境缺失时保留业务配置并报告未完成。
- 接入分配区分 PENDING/ACTIVE：仅实际入口验证通过后，中央节点停止接收该同机站点；回退上报后可以解除分配。节点凭据独立于 Agent 凭据，绑定资产凭据代次，不下发全局 WAF 密钥。

- 最终审阅修复：保留原 Nginx 回源 Host（包括默认 proxy_host 与明确 Host），通过仅可信本机入口启用的内部元数据转交；外部伪造该字段不能改变回源 Host，转发前移除内部字段。
- 最终审阅修复：复制非秘密的管理 CA 为节点可读的只读证书文件，避免采集用户私有 CA 权限导致 WAF 无法上报。原 CA 权限不变。
- 0.4.5/序列36仅生成本地签名候选，未发布；上述修复进入 0.4.6/序列37，旧制品保留，不覆盖。

- 中断场景：读取任何报文前先持久化私有授权及PCAP清理期限；已有输出目录不得覆盖。时长使用单调经过时间预算，不使用报告墙上时钟作为停止依据。
- 以太网出站实测发现环回去重误作用于全部网卡，修正后内部隔离网络真实UDP出站验证通过；环回仍只保留一次。最终为0.4.8/序列39；0.4.6已撤回，0.4.7仅保留本地候选。

- 最后验收修复：正常/检测探针共同等待真实WAF记录，容忍Nginx重载时旧/新工作进程交接；真实链路测试复用生产验收函数，消除日志读取的数据竞争。最终发行冻结为0.4.9/序列40，0.4.8候选未发布。
