# 授权对象选择目录

落实建设方案第18节：选择已有对象时只展示身份、名称和必要状态，不读取整份资产清单或风险证据；所有查询沿用当前账号的数据范围。既有创建、编辑和扫描接口继续独立核对权限，不能以选择目录代替最终授权。

1. 添加资产、风险、任务、站点和业务的轻量目录，默认15条、可检索、可读回已选名称。验证：跨页、超过100条、受限账号、已归档对象与必要字段。
2. 业务使用已有名称选择，管理员及具有完整范围的分析员可明确创建业务；资产创建或归属调整时保留对应稳定业务身份。验证：重复创建、归属调整、清空、未授权业务及历史身份保持。
3. API通过独立验收后再切换前端目录，补齐业务选择和创建说明，保留错误重试与旧请求失效。验证：五种分辨率、授权对象不泄露、名称回显和最终提交身份。
4. 详情内的编辑、驳回、复测和密码表单放回当前详情，保留一次提交与错误重试；创建记录等页面操作沿用独立表单。验证：先复现现有二次弹窗，再验证五种宽度、必填校验、实际提交、关闭和菜单跳转时不残留旧表单。

WAF持续验收期间仅修改源文件和准备测试，不构建或重启其API、运行程序和测试驱动。新的目录在完整验证前不切换当前页面使用的接口。

待执行验证：`record-options.test.ts` 使用新建独立数据库模式检查目录和业务身份；`record-options-http.test.ts` 在独立 HTTP 验收服务检查真实登录、路由、权限和字段边界；`record-select-ui-smoke.cjs` 与 `business-select-ui-smoke.cjs` 只修改受控页面夹具，检查五种宽度下的分页、重试、业务创建与清空。测试文件存在不代表测试已经通过。
