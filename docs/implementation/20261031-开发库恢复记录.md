## 后续约束

- 禁止把业务库、共享开发库连接作为影子库。迁移 diff 使用 `--from-url` 对照 schema 时只做只读检查，输出不得直接执行。
- 需要影子库时必须新建本任务专用空数据库，并验证其名称与业务连接不同；单元/集成测试仍使用随机隔离 schema。
